# NDVI

## English Name
Normalized Difference Vegetation Index (NDVI)

## Definition
NDVI 是常見的植生指標，用來描述植被在 Red 與 Near Infrared (NIR) 波段上的光譜差異。

## Formula/Key Information
NDVI = (ρNIR - ρRed) / (ρNIR + ρRed)

其中：
- ρNIR：Near Infrared reflectance
- ρRed：Red reflectance

## Interpretation
一般而言，較高的 NDVI 通常代表較強的綠色植被訊號；較低值可能代表裸地、水體、建成區或稀疏植被。

NDVI 的實際解讀仍需搭配土地覆蓋、季節與影像品質。

## Applications
- Vegetation monitoring
- Crop monitoring
- Land cover analysis
- Change detection
- Fire impact analysis
