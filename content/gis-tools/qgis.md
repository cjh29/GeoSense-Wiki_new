# QGIS

## English Name
QGIS

## Overview
QGIS 是開源的 Desktop GIS 軟體，可用於處理、分析與視覺化 raster 與 vector spatial data。

## Main Functions
- Raster data processing
- Vector data processing
- Coordinate reference system management
- Raster Calculator
- Spatial analysis
- Map visualization

## GIS Applications
- Spatial data visualization
- Vector and raster analysis
- Map production
- Coordinate transformation

## Remote Sensing Applications
- Satellite image visualization
- Image clipping
- Raster calculation
- NDVI / NDWI analysis
- Cloud masking
- Land Surface Temperature analysis
- Classification and image processing workflows
