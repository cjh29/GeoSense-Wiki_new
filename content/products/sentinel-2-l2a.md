# Sentinel-2 L2A

## English Name
Sentinel-2 Level-2A

## Overview
Sentinel-2 L2A 是由 Sentinel-2 Level-1C 經大氣校正後產生的 Surface Reflectance 產品，可用於較直接的地表光譜分析。

## Data/Product Information
- Product level：Level-2A
- 主要資料：Surface Reflectance
- 相關資訊：Aerosol Optical Thickness (AOT)、Water Vapour (WV)
- Scene Classification Layer (SCL) 可協助進行像元分類與品質判斷
- 相較 Level-1C，更適合直接進行地表反射率分析

## Applications
- Vegetation analysis
- Water analysis
- Land cover classification
- Change detection
- Atmospheric correction-based analysis
